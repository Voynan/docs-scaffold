# Terms

Versioned public legal texts: terms of service and privacy policy.

## What goes here

- The full text of each published version
- A changelog summarizing what changed between versions

## Rules

- Published versions are never edited. A change is a new file.
- Each version records its effective date. The application stores which version each user accepted, so the version identifier must match what the application records.

## Naming

`<document>-YYYY-MM-DD.md`, dated by the effective date, e.g. `terms-of-service-2026-11-01.md`, `privacy-policy-2026-11-01.md`.
