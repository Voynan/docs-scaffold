# Knowledge

Descriptive knowledge: the context and evidence that inform decisions. Nothing here is normative; a requirement or decision that depends on it lives elsewhere and cites it.

## What goes here

| Folder                         | Content                                                          |
| ------------------------------ | ---------------------------------------------------------------- |
| [product/](product/README.md)  | Vision, value proposition, personas, competitors, roadmap        |
| [domain/](domain/README.md)    | The client's business rules as described by them, legislation, glossary |
| [research/](research/README.md) | Dated research notes and spikes that feed decisions             |

## What does not go here

- Requirements the system must meet → [requirements/](../requirements/README.md), [stories/](../stories/README.md)
- Decisions → [decisions/](../decisions/README.md)
