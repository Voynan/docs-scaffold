# Research

Dated research notes and spikes that feed decisions.

## What goes here

- Technology evaluations, benchmarks, spike results, market or user research
- One question per note

## What does not go here

- The decision itself → [decisions/](../../decisions/README.md), which cites the note
- Ongoing personal investigation → [dev/investigations/](../../dev/README.md)

## Rules

- Notes are never rewritten. When outdated, set `status: superseded` and `superseded_by:` in the front matter, and write a new note.
- The file stem is the note's ID: `2026-10-payment-gateways`.

## Naming

`YYYY-MM-slug.md`, e.g. `2026-10-payment-gateways.md`.
