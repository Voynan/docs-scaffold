# Onboarding

Where to start on this project, and what to read first. This page links to the material; it does not repeat it.

## Reading order

1. [knowledge/product/](../knowledge/product/README.md) — what the product is and who it serves
2. [knowledge/domain/](../knowledge/domain/README.md) — the business and its vocabulary
3. [architecture/](../architecture/README.md) — how the system is built today
4. [decisions/](../decisions/README.md) — why it is built this way; read accepted ADRs, newest first
5. [guides/](README.md) — set up your machine and learn how we work
6. [operations/](../operations/README.md) — how production runs

## First week

- [ ] Get access: repository, GitHub Projects, password manager, Railway, Sentry, PostHog, Figma
- [ ] Run the app and the test suite locally following `local-setup.md`
- [ ] Ship one small change end to end, through review and deploy
- [ ] Fix anything on this page that was wrong or missing
