# Guides

How we work on this codebase, from the first day onwards.

## What goes here

- [onboarding.md](onboarding.md) — where a newcomer starts and what to read first
- `local-setup.md` — from a clean machine to a running app and passing tests
- `code-conventions.md` — style, structure, naming, error handling
- `git-workflow.md` — branching, pull requests, reviews, merging
- `commits.md` — commit message convention
- Anything a developer learned in `dev/` that other developers need

## What does not go here

- Production procedures → [operations/runbooks/](../operations/runbooks/README.md)
- Rules a linter or formatter already enforces → the tool's configuration; link to it

## Naming

Lowercase kebab-case, one topic per file.
