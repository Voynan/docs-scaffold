# PRDs

One Product Requirements Document per epic: the problem, goals, success metrics and scope.

## What goes here

- Problem statement with evidence
- Goals, non-goals and measurable success metrics
- Scope, constraints, risks and release plan

## What does not go here

- Acceptance criteria → [stories/](../stories/README.md)
- Technical design → [decisions/](../decisions/README.md), [architecture/](../architecture/README.md)
- The list of stories: stories cite their PRD, and the list is generated

## Naming

`PRD-NNN-slug.md`, e.g. `PRD-001-billing.md`.
