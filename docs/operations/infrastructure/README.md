# Infrastructure

What runs where, and what it costs.

## What goes here

- `services.md` — every service and account (Railway, R2, DNS, Sentry, ...): purpose, owner, environment, plan, where its credentials are stored
- `environments.md` — environments, their URLs, differences and how data flows between them
- `costs.md` — monthly cost per service, with the date of the last review

## What does not go here

- Infrastructure as code → the repository that applies it; link to it
- Secrets → the password manager
