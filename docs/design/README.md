# Design

How the product looks and behaves for the user.

## What goes here

- Design system: tokens, components and usage rules, or the link to where they live
- Wireframes and screen flows, as Figma links with a short description
- UX decisions: what was decided, the alternatives and why

## What does not go here

- System-level diagrams → [architecture/diagrams/](../architecture/diagrams/README.md)
- Behavior requirements → acceptance criteria in [stories/](../stories/README.md)

## Rules

- Every Figma link names the file and frame and states the date it was last checked against the product.

## Naming

Lowercase kebab-case, one topic per file.
